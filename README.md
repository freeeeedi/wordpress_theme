# Кастомная тема Wordpress

## Описание проекта

В этой теме WordPress реализовано:

- **Кастомные типы записи "news" и "events"**.

- Формы **регистрации и авторизации** пользователя с обработкой запросов через ajax.

- Создан **компонент поиска** для поиска записей в типах записей "news" и "events".
